⚠️ Problems to Solve & Challenges
Slide 2 / 10
Core Pain Points

The Polar Archive Bottlenecks

  • Description Vacuum: UKAHT's decades of assets (visitor photos, condition record images, and artefact images from multiple sites) are unorganized and lack metadata, making search and labeling extremely inefficient.
  • Polar Model Domain Drift: General-purpose AI models (e.g., standard CLIP) fail to recognize specific polar concepts (old tents, and base structures) due to training set biases.
  • Interrogation Barriers: Curators cannot query the visual archive using natural language or link photos dynamically to historical text metadata.
Technical Challenge

Why Basic Searches Fail

Basic searches cannot resolve complex semantic relationships or match visual context. Additionally, standard vector databases lack the ability to handle exact relational queries (like dates, categories, or site locations). We must bridge this gap by introducing a custom representation projection and a reasoning LLM core.

❄️ Innovation I: Polar Domain Adaptation
Slide 6 / 10
Contrastive Learning

MLP Projection Adapter

To resolve semantic gaps in vanilla CLIP (e.g., misidentifying historical wooden sledges or Antarctic equipment), we propose to implement a lightweight projection adapter model.

  • Architecture: A feed-forward network with linear mappings and activation layers that projects CLIP image vectors into a refined target space.
  • Triplet Loss Formulation: Maximizes the distance between unrelated descriptions and images while pulling matching polar descriptions closer.
L = max(0, d(f(a), f(p)) - d(f(a), f(n)) + margin)

Positive & Negative Slices

Positive samples (Anchor image + Golden caption) will be matched against negative samples (Anchor image + Random non-matching caption) to optimize embedding clusters.

Planned t-SNE Space Visualization

To be visualized using low-dimensional t-SNE mapping, evaluating how polar-specific concepts cluster tighter together post-training.

🧠 Innovation II: LLM ReAct Agent & Hybrid Search
Slide 7 / 10
Brain Logic

The ReAct Cycle

Rather than standard static searches, the system will employ a ReAct LLM Agent. It will parse the intent of user questions, maintain chat history, and call the appropriate tools dynamically.

1

Thought: Parse Intent

"User is asking for sledges taken in 1960. I need to filter metadata and vector similarity."

2

Action: Tool Execution

Call `sqlite_query` for date filter AND `vector_search` with polar MLP adapter.

Hybrid Integration

Why Hybrid RAG?

  • Vector Search Limitations: High-dimensional embeddings struggle to filter exact metadata, such as exact dates or catalog numbers.
  • SQL Database Limitations: Relational queries fail to process abstract visual attributes or natural language queries (e.g., "warm clothing vs expedition uniforms").
  • Solution: The LLM Agent will synthesize search results from BOTH vector embeddings and SQL metadata tables, injecting both into the generation prompt.

🛡️ Data Strategy & Risk Management
Slide 10 / 10
Data Requirements

Target Data Assets

  • Photographic Dataset: Ingesting a 3.3 GB historical photo archive from UKAHT covering landscapes, scientific surveys, and expeditions.
  • Golden Test Set: Curating 50–100 high-quality verified image-text pairs covering main thematic categories to conduct quantitative evaluations.
  • Auto-Caption Generation: Utilizing batch BLIP models to generate initial descriptions directly into the database.
Risk Mitigation

Plan B Execution Strategy

What if manual descriptions or annotations are insufficient or delayed?

  • Primary Dependency: The primary dataset consists of the photographs themselves, which are fully available.
  • LLM-Assisted Curation: Use advanced multimodal LLMs to generate high-quality draft descriptions to bootstrap annotations.
  • Human-in-the-Loop: Focus manual validation only on the core golden validation subset rather than the entire collection.
